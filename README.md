# bfoundry.co.uk

The BFoundry website: a plain static site (HTML, CSS and a little JavaScript), hosted on GitHub Pages.

- Preview locally: open `index.html` in a browser, or run `python -m http.server` in this folder and go to http://localhost:8000
- Publish: commit and push to `main`. GitHub Pages redeploys within a minute or two.
- Editing guidance and brand rules: see `CLAUDE.md`.
